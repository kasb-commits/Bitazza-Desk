## Setting Up 2FA (Website)

1. Click the account icon → **Profile & Security**
2. Find the Two-Factor Authentication section and click **Enable**
3. Scan the QR code with Google Authenticator or Authy
   - In Google Authenticator: tap + → Scan QR code
   - Label the account "Bitazza TH" for easy identification
4. Enter the 6-digit code shown in the app to confirm
5. Codes refresh every 30 seconds — use the current code before it expires

---

## Setting Up 2FA (Mobile App)

1. Go to **Settings → Security → Enable 2FA**
2. Copy the key shown on screen
3. Open Google Authenticator or Authy and add a new account manually using the key
4. Enter the 6-digit code generated to complete setup

---

## Transferring 2FA to a New Device

**Always transfer 2FA before switching or wiping your old device.**

### Google Authenticator
1. On the **old device**: open Google Authenticator → tap menu → **Transfer accounts → Export accounts**
2. Select the Bitazza account and generate a QR code
3. On the **new device**: open Google Authenticator → **Import existing accounts** → scan the QR code

### Authy
1. On the **old device**: go to Settings → Accounts → **Enable multi-device**
2. On the **new device**: install Authy and add an account using your registered phone number
3. Approve the new device from the old one
4. After transfer is complete, disable multi-device for security

## 2FA Troubleshooting (Wrong Code Error)

If your 2FA codes are being rejected, the most common cause is a time sync issue:

**Android:**
1. Open Google Authenticator → tap the three-dot menu → **Time correction for codes → Sync now**

**iOS:**
1. Go to **Settings → General → Date & Time**
2. Toggle **"Set Automatically"** off, then back on
3. Restart the app; if still failing, restart the device

If the issue persists after syncing, contact support: **+66-2-171-2417**

## How to Reset 2FA (Lost Phone / Can't Access Codes)

If you have lost your device or can no longer access your 2FA codes, contact Bitazza support with the following:

**Submit a selfie photo holding your ID** with a **handwritten note** that includes:
- Website: **bitazza.co.th**
- Request type: **Reset 2FA**
- Reason for reset
- Today's date

**Accepted ID:**
- Thai National ID card
- Passport

**Submit via:**
- Form: https://shorturl.at/lzT7o
- Email: support@bitazza.com
- Live chat with a support agent

**Processing time:** Within 24 hours of document verification.

> **Important:** Never share your 2FA codes or secret key with anyone, including Bitazza staff. Support will never ask for your 2FA code.
